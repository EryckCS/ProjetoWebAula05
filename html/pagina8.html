Ferramentas do Engenheiro de IA

Linguagens e frameworks

O desenvolvimento de sistemas de Inteligência Artificial envolve diferentes ferramentas. A escolha depende do tipo de aplicação, do modelo utilizado, da infraestrutura disponível e das necessidades do projeto.
Python é uma das linguagens mais utilizadas na área devido ao seu ecossistema de bibliotecas para manipulação de dados, Machine Learning e Deep Learning. Além da linguagem, existem frameworks especializados que facilitam a construção e o treinamento de modelos.
PyTorch é amplamente utilizado para desenvolvimento e pesquisa envolvendo redes neurais e Deep Learning. TensorFlow também fornece ferramentas para construção, treinamento e utilização de modelos de Machine Learning.
Entretanto, o trabalho de um engenheiro de IA não termina no treinamento de um modelo. Aplicações reais também podem exigir APIs, bancos de dados, servidores, controle de versões, monitoramento e outras ferramentas tradicionais da Engenharia de Software.


Ferramentas para aplicações com LLMs

O crescimento dos grandes modelos de linguagem também levou ao desenvolvimento de ferramentas especializadas na criação de aplicações baseadas em LLMs.
LangChain, por exemplo, oferece componentes que podem auxiliar na integração de modelos de linguagem com outras partes de uma aplicação, incluindo ferramentas, recuperação de documentos e diferentes fontes de dados.
Ollama é uma ferramenta que facilita a execução de diferentes modelos de linguagem em computadores locais compatíveis, sendo útil para estudos, testes e desenvolvimento de aplicações locais.
Bancos de dados vetoriais e bibliotecas de busca vetorial também são utilizados em sistemas que precisam trabalhar com embeddings e recuperação de informações, especialmente em aplicações RAG.
Na prática, diferentes ferramentas podem ser combinadas. Uma aplicação pode utilizar Python para sua programação, um modelo de linguagem para geração, embeddings para representar documentos e um banco vetorial para realizar a recuperação de informações.
