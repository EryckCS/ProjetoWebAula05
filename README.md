# ProjetoWebAula05

Site educativo sobre Engenharia de Inteligência Artificial, desenvolvido em HTML com páginas temáticas sobre IA, Machine Learning, Deep Learning, LLMs, RAG e aplicações reais da tecnologia.

## Objetivo

Este projeto foi criado para apresentar de forma clara e acessível os principais conceitos da Inteligência Artificial e da Engenharia de IA, incluindo:

- história e fundamentos da IA
- Machine Learning e Deep Learning
- grandes modelos de linguagem (LLMs)
- RAG e bancos vetoriais
- ferramentas utilizadas por profissionais da área
- aplicações reais da IA em diferentes setores

## Estrutura do projeto

- html/: arquivos HTML das páginas do site
- audio/: arquivos de áudio usados no conteúdo
- image/: pasta destinada a imagens do projeto
- video/: pasta destinada a vídeos do projeto
- README.md: documentação do projeto

## Páginas do site

O projeto contém 10 páginas principais:

1. Página 1 — Engenharia de IA
2. Página 2 — O que é Engenharia de IA?
3. Página 3 — História da IA
4. Página 4 — O que é Machine Learning?
5. Página 5 — O que é Deep Learning?
6. Página 6 — O que são LLMs?
7. Página 7 — RAG e Bancos Vetoriais
8. Página 8 — Ferramentas do Engenheiro de IA
9. Página 9 — Inteligência Artificial no Mundo Real
10. Página 10 — Quiz sobre Inteligência Artificial

## Como visualizar o projeto

### Opção 1: abrir diretamente no navegador
- Acesse a pasta html
- Abra o arquivo pagina1.html no navegador
